# SNTL84 · Multilingual Statement Generator

> Client Conversion Statements — 29 statements · 39 languages · 1,131 translations → .xlsx

A client-side HTML tool that uses **Claude AI (Anthropic API)** to translate 29 professional sales/business statements into 39 languages and exports them as a formatted Excel (.xlsx) file.

## 🚀 Features

- 29 conversion-optimized sales statements across 7 categories
- 39 languages including all 22 Indian official languages + global languages
- Real-time translation progress with status indicators
- One-click Excel export with a master sheet + per-language sheets
- 100% client-side — no server, no data stored
- Built with dark UI matching SNTL84 brand identity

## ⚡ How to Use

1. Open `index.html` in your browser
2. Enter your [Anthropic API key](https://console.anthropic.com/settings/keys)
3. Click **▶ Generate All Translations**
4. Wait ~3–5 minutes for all 39 languages
5. Click **↓ Download Excel (.xlsx)**
