## 🔴 Problem

Freelancers, global sales teams, and D2C brands expanding into new markets need **localized sales copy** — but professional translation costs ₹500–1,500 per statement per language. A 29-statement pitch deck in 39 languages would cost **₹5+ lakhs** and take weeks. Most businesses either skip localisation entirely or rely on Google Translate copy-paste (which breaks formatting and loses context).

---

## 🛠️ What I Built

**Multilingual Client Conversion Statement Generator** — a browser-based tool that generates all translations instantly with one click:

- **29 proven client conversion statements** (objection handling, trust-building, urgency, value) 
- **39 languages** — Hindi, Arabic, Spanish, French, Mandarin, Swahili, Gujarati, and more
- **1,131 unique translations** generated in a single session
- **One-click XLSX export** — opens directly in Excel, formatted and ready to use
- No backend, no API keys, no subscriptions — runs entirely in the browser
