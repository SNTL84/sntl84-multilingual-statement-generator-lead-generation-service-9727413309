# 🤝 Contributing to SNTL84 Multilingual Statement Generator

Thank you for your interest! This project welcomes contributions from multilingual developers, translators, marketers, and automation engineers.

---

## 📋 How to Contribute

### 1. Fork & Clone
```bash
git clone https://github.com/SNTL84/SNTL84-multilingual-statement-generator.git
cd SNTL84-multilingual-statement-generator
```

### 2. Create a Feature Branch
```bash
git checkout -b feature/your-feature-name
```

### 3. Make Your Changes
- Open the HTML file directly in a browser
- No build step required

### 4. Commit & Push
```bash
git commit -m "feat: describe your change"
git push origin feature/your-feature-name
```

### 5. Open a Pull Request
Describe what you changed and why.
